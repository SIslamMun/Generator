# Complete benchmark metrics on real Jarvis MCP

Source: `benchmark_COMBINED.jsonl` — 1044 rows across 15 models × {1, 3, 3} runs at T∈{0.0, 0.3, 0.7} × 12 held-out cases.

Definitions:

- **task_success** — the run was correct end-to-end: `tool_ok ∧ arg_ok ∧ mcp_errors==0`.
- **tool_ok** — the expected sequence of tools (ordered or any-of) was called.
- **arg_ok** — `tool_ok` AND each expected argument value is present in the actual call.
- **answer_ok** — the final text answer semantically matches the expected answer.
- **hallucinations** — tool calls naming a tool NOT in the 29-tool Jarvis catalog.
- **mcp_errors** — real jarvis-mcp responded with an error payload to a call.
- **n_calls** — total tool calls emitted in that run.
- **gen_s / tot_s** — wall-clock: generation only / gen + MCP round-trips.
